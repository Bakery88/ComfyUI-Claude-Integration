# Sample Captions: Amano Watercolor LoRA

## Captioning Guidelines

### Structure
Every caption follows this pattern:
```
[trigger], [medium + style], [subject], [composition/pose], [key visual details], [color palette], [atmosphere]
```

### Rules
1. **Trigger token** (`amano_watercolor`) MUST appear at the start of every caption
2. Use **natural language**, not danbooru-style tags
3. Describe what makes the image distinctly "Amano" -- elongated proportions, flowing linework, watercolor effects
4. Include character names when identifiable (helps the model learn subject-style associations)
5. Describe the **color palette** specifically -- Amano's palette is one of his most distinctive features
6. Mention medium-specific effects: watercolor blooms, ink splatters, paper texture, translucent washes
7. Keep captions **50-150 words** -- long enough to be descriptive, short enough to be useful
8. Do NOT include meta-information like "scan from artbook" or "official art" -- describe what the image looks like, not what it is

## Caption Variation Notes

### Things to Vary Across Captions
- Subject type (character, landscape, abstract, group, creature)
- Level of detail described (some images are more minimal, some are dense)
- Color palette specifics (varies significantly across Amano's work)
- Composition orientation (vertical, horizontal, diagonal, centered, off-center)
- Linework density (some works are line-heavy, others are wash-dominant)
- Mood/atmosphere vocabulary (ethereal, dark, heroic, contemplative, romantic)

### Things to Keep Consistent
- Trigger token always first
- Medium always mentioned (watercolor, ink, traditional media)
- Amano-specific vocabulary: elongated, calligraphic, Art Nouveau, translucent, ethereal
- Color specificity (use actual color names, not just "colorful")
- Paper/texture mention when visible

### Common Amano Vocabulary for Captions
- **Linework**: calligraphic, fluid, gossamer, sweeping, decisive, trailing, flourish
- **Watercolor**: translucent, wash, bloom, wet-on-wet, granulated, layered, bleed
- **Proportions**: elongated, willowy, attenuated, slender, ethereal
- **Style**: Art Nouveau, ornamental, decorative, organic
- **Atmosphere**: ethereal, dreamlike, liminal, haunting, romantic, melancholic
- **Composition**: negative space, asymmetric, flowing, dynamic, suspended
